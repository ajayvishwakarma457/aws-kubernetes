Install a Local Kubernetes Cluster

  To try Kubernetes locally without using cloud providers, you can use either:
  Minikube → runs a single-node cluster on your laptop with helpful add-ons.
  kind (Kubernetes in Docker) → lightweight clusters inside Docker, great for quick testing.
  Both are good for learning and experimenting.


Basic kubectl Commands
  Once your cluster is running, use kubectl (the Kubernetes CLI) to interact with it:


| Command                        | What it does                                |
| ------------------------------ | ------------------------------------------- |
| `kubectl get pods`             | List all pods                               |
| `kubectl describe pod <name>`  | Show detailed info and events for a pod     |
| `kubectl apply -f file.yaml`   | Create or update resources from a YAML file |
| `kubectl logs <pod>`           | View logs from a running pod                |
| `kubectl exec -it <pod> -- sh` | Open a shell inside a container             |


✅ Summary: Use Minikube or kind to spin up a local cluster, then practice managing it with basic kubectl commands.
